# Giumag PDF

**Private PDF tools. Processed on-device.**

Giumag PDF is the production-oriented successor to the original Giumag PDF Studio prototype. The project is designed as one product with three delivery targets:

- **Web / PWA** — instant access from a URL, installable, offline-capable after first load.
- **Desktop** — Windows, macOS and Linux through Tauri 2.
- **Mobile** — iOS and Android through Capacitor.

The product architecture is **local-first**: PDF contents are processed on the user's device. The production web application must not expose document-upload endpoints.

## Repository status

This repository is a production architecture baseline and migration scaffold. The previous Python/FastAPI proof of concept is preserved under `legacy/python-prototype/` as a functional reference, not as the intended production runtime.

## Product name

The public product name is **Giumag PDF**. Avoid informal copy such as “firmata da Giumag” in the application. Legal ownership, copyright and publisher identity belong in the About screen, store metadata and legal documents.

## Development policy

- No remote fonts, CDNs or analytics in the application bundle.
- No PDF upload API in the web production architecture.
- Processing libraries must pass a license review before inclusion.
- Heavy processing runs in workers / native commands, never on the UI thread.
- Every feature declares platform support and engine requirements.
- Releases are reproducible, signed and generated by CI where possible.
